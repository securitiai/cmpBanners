What a consent banner actually records

Privacy basics · 5 min read

When a visitor makes a choice on a consent banner, the CMP stores that choice and shares it with the scripts on the page. Under the IAB Transparency and Consent Framework, the choice is encoded in a compact TC String that lists every purpose, special feature and vendor the visitor agreed to.

Advertising and measurement tags read the TC String through the __tcfapi JavaScript API before they set cookies or send requests. If the string says no, a compliant tag stays silent or falls back to limited, non-personalised behaviour.

The eleven TCF purposes in plain language

IAB TCF v2.2 · 7 min read

TCF v2.2 defines eleven purposes. They range from storing information on a device (Purpose 1), through building and using advertising and content profiles (Purposes 3 to 6), to measuring performance, understanding audiences and improving services (Purposes 7 to 10).

Each purpose can rely on consent, and some can also rely on legitimate interest. Visitors can object to legitimate interest in the preference center, and that objection must be reflected in the TC String just like a withdrawn consent.

Why changing your mind has to work instantly

Consent lifecycle · 4 min read

Regulators expect withdrawing consent to be as easy as giving it. That means the preference center must always be reachable, for example from a persistent "Manage Cookie Preferences" link, and every saved change must produce a new TC String.

Scripts that registered a listener with addEventListener receive the updated string straight away, so ad requests made after the change carry the visitor's latest choice.

Auto-blocking: stopping tags before consent

Implementation · 6 min read

An auto-blocking script placed first in the page head holds back known tracking scripts until the visitor has made a choice. Once consent is given, the blocked scripts are released in their original order.

Placement matters: if any tracking tag runs before the auto-blocking script, it can set cookies before the visitor has seen the banner.

Global Privacy Control and the browser signal

Opt-out signals · 4 min read

Some browsers and extensions send a Global Privacy Control (GPC) signal with every request. In opt-out regions, a CMP can treat this signal as the visitor's request to opt out of the sale or sharing of personal data, without the visitor having to click anything.

Google Consent Mode alongside TCF

Integrations · 5 min read

Google tags can read consent from the TC String directly, and many sites also send Google Consent Mode signals such as ad_storage and analytics_storage. Keeping both in step means the visitor's single choice controls every Google product on the page.

Testing a CMP before going live

Checklist · 3 min read

  • The banner appears on the first visit from a region where TCF applies.
  • __tcfapi('ping') returns cmpLoaded: true.
  • Accept, Reject and Save each produce a TC String that matches the choice.
  • The preference center can be reopened from every page.
  • No tracking cookies are set before the visitor makes a choice.
